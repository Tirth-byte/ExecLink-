# Demo Engineering

## Mission
Make the judge/demo flow deterministic, believable, and resilient.

## Requirements
- Known seed/reset command.
- Stable project/demo IDs.
- Golden path works from a clean reset.
- Every primary demo button works.
- No accidental empty screen in the scripted flow.
- Synthetic data is realistic and internally consistent.
- Demonstrate strong, ambiguous, and unmatched matching.
- Demonstrate human verification before mutation.
- Demonstrate auditability.
- Demonstrate field capture and DPR ingestion.
- Demonstrate analytics update and Project Memory.
- Keep offline fallback available only as explicit resilience, not as a substitute for real integration.

## Rehearsal
Run the complete story from reset multiple times. Record exact routes, actions, expected values, and recovery path for network/service failure.
