# Interaction and Motion

## Mission
Use motion to communicate state and causality without making enterprise software theatrical.

## Timing Guidance
- micro feedback ~120ms
- drawers/popovers ~180–220ms
- larger transitions ~240ms

## Use Motion For
- opening contextual drawers
- arrival of a new execution event
- filter/result transitions
- verification success
- progressive disclosure
- state changes users need to notice

## Avoid
- perpetual decorative animation
- bouncy cards
- animated gradients
- page transitions that delay work
- motion on every hover
- hiding latency behind excessive animation

Respect reduced-motion preferences.
