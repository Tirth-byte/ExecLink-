# Premium Enterprise UI

## Mission
Make ExecLink feel like polished operational SaaS used by professional project-controls teams.

## Visual Character
Precision. Calm. Trust. Engineering. Operational density.

## Surface Language
- Light neutral application background; white/near-white working surfaces.
- Thin restrained borders; shadows only when elevation communicates something.
- Moderate radii, generally 8–14px; pills reserved for compact statuses/tags.
- Deep restrained green may act as product accent; blue for informational/planned states; semantic green/amber/red for verified/review/critical.
- Never turn the product into a rainbow of card colors.

## Enterprise Patterns
Favor:
- dense data tables
- filter bars
- split panes
- resizable working areas where useful
- right-side detail drawers
- WBS trees
- timelines
- audit trails
- evidence viewers
- confidence breakdowns
- saved operational views

Avoid:
- landing-page hero layouts inside the app
- meaningless stat cards
- decorative chart grids
- oversized icons
- “AI assistant” chat bubbles as the primary product metaphor

## Acceptance
A screenshot with branding removed should still look like a credible enterprise product, not a student dashboard template.
