# UX and Information Architecture

## Mission
Make complex project-control workflows understandable without oversimplifying them.

## Principles
- Organize around user jobs, not backend entities.
- Keep capture, review, verification, schedule exploration, analytics, and memory conceptually distinct.
- Use progressive disclosure: summary → detail → evidence/history.
- Preserve context with drawers/split views where appropriate.
- Filters must match real operational questions.
- Avoid duplicate pages that solve the same job.
- Primary action should be obvious; destructive/irreversible actions need appropriate confirmation.
- Use domain terminology consistently.

## Key Distinction
Match Review deeply resolves one proposal.
Verification Center manages the human approval workload.
Do not collapse them into the same generic table.

## Mobile
Optimize for rapid field capture. Never reproduce the full desktop control center on a phone.
