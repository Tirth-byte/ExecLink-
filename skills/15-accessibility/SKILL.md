# Accessibility

## Mission
Ensure professional usability beyond mouse-only visual demos.

## Requirements
- Semantic HTML where applicable.
- Keyboard-accessible navigation and actions.
- Visible focus states.
- Inputs/buttons have accessible names.
- Dialogs/drawers manage focus correctly.
- Status is not communicated by color alone.
- Maintain sufficient contrast.
- Icons used as controls require labels/tooltips.
- Tables need sensible headers.
- Respect reduced-motion preferences.
- Error messages should identify the affected field/action.

Accessibility should be built into components rather than patched at the end.
